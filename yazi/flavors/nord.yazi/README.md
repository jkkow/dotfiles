# Nord Flavor

Nord is the active flavor and is pinned in `yazi/package.toml`.

## Windows

### Install

Install Yazi using `yazi/README.md`.

### Configure

```powershell
Set-Location "$HOME\.config\yazi"
ya pkg install
```

## Ubuntu

### Install

Install Yazi using `yazi/README.md`.

### Configure

```sh
cd "$HOME/.config/yazi"
ya pkg install
```

## Omarchy

### Install

Install Yazi using `yazi/README.md`.

### Configure

```sh
cd "$HOME/.config/yazi"
ya pkg install
```

Restore the repository default in `theme.toml`:

```toml
[flavor]
dark = "nord"
light = "nord"
```
