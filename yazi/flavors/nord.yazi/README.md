# Nord Flavor for Yazi

Nord color flavor package for [Yazi](https://github.com/sxyazi/yazi).

## Install

Latest Yazi:

```sh
ya pkg add AdithyanA2005/nord
```

Yazi `<= 25.5.28`:

```sh
ya pack -a AdithyanA2005/nord
```

## Use

Set `theme.toml`:

```toml
[flavor]
dark = "nord"
```

Keep only `[flavor]` in `theme.toml` unless you intentionally override styles.
